Import de fichier

Chaque enquête à importer est décrite par une ligne dans un fichier CSV. Le XML qui documente son contenu est soit téléchargé automatiquement depuis une URL indiquée dans le CSV, soit déposé directement ci-dessous — dans ce cas, déposez-le avant d'importer le CSV, sinon l'import échouera faute de fichier trouvé pour ce DOI.

Étape 1
Fichier CSV

Une ligne par enquête, avec son DOI, sa collection et une URL de téléchargement du DDI-C.

  • Requis doi
  • Requis collection
  • Requis sub_collection
  • Requis, peut être vide url
Optionnel
Dépôt XML direct

Pas d'URL de téléchargement pour une enquête ? Déposez son XML ici, il sera retrouvé automatiquement par DOI.

  1. Déposez le(s) fichier(s) XML ici
  2. Laissez url vide pour ce DOI dans le CSV
  3. Importez le CSV normalement
